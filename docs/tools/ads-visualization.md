# ADS 算法可视化

[打开算法可视化工具](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html){ .md-button .md-button--primary target="_blank" rel="noopener noreferrer" }

由 University of San Francisco 的 David Galles 提供的 **Data Structure Visualizations**，通过交互动画展示数据结构操作与算法执行过程，辅助 ADS 课程理解。

## 适合配合课程查看的内容

- **树结构**：二叉搜索树、AVL 树、红黑树、伸展树、B 树与 B+ 树。
- **优先队列与堆**：二项队列、斐波那契堆、左式堆与斜堆。
- **排序与图算法**：排序过程、BFS / DFS、最短路径、最小生成树和拓扑排序。
- **其他**：并查集、哈希表及部分动态规划问题。

## 使用建议

选择正在学习的算法，从少量数据开始，先自己推演插入、删除、合并等操作，再通过动画核对结构变化。复杂度分析仍需结合课件和代码，动画主要帮助理解执行过程。

原站：[Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html)。
